# 📂 Repositório

Repositório de projetos relacionados à **análise de dados** e **ciência de dados**, incluindo desde o pré-processamento até a construção de modelos de **machine learning** e **redes neurais**.

---

## 🚀 Technical Skills  

### 🖥️ Linguagens de Programação  
- 🐍 **Python**  - 🗄️ **SQL**  

### 📊 Análise de Dados  
- 🧩 **Pandas**  - 🔢 **NumPy**  - 📉 **Matplotlib**  - 📊 **Seaborn**  - 📈 **Power BI**  

### 🤖 Machine Learning & IA  
- ⚡ **Scikit-learn** (Classificação e Regressão)  
- 📐 **Statsmodels** (Regressão Linear OLS)  
- 🧠 **Keras/TensorFlow** (Redes Neurais)  

---

## 📂 Estrutura do Repositório  

- **AnaliseDeDados/** → scripts de análise exploratória e visualização de dados com Python e Power BI.  
- **pre_processamento_dados/** → limpeza, transformação e preparação de datasets.  
- **MachineLearning_Classification/** → modelos de machine learning tradicionais para Classificação.
- **MachineLearning_Regression/** → modelos de regressão linear e múltipla.
- **redesNeurais_Keras/** → experimentos com deep learning utilizando Keras/TensorFlow.  

---

## 📌 Objetivo  

Este repositório foi criado para servir como portfólio de projetos em **Data Science**, reunindo estudos e aplicações práticas em **análise de dados**, **estatística** e **machine learning**.
